# أبو بشار ستورز - متجر العملاء

واجهة متجر إلكتروني فاخرة مبنية بـ **Next.js 15 (App Router) + TypeScript + Tailwind CSS**
بثيم ملكي (أسود مطفي + ذهب `#D4AF37`) مع دعم كامل للعربية واتجاه RTL.

## المميزات
- صفحة رئيسية ببانر وأقسام ومنتجات مميزة وشارات خصم.
- استعراض المنتجات والتصفية حسب الفئة والبحث.
- صفحة تفاصيل المنتج بمعرض صور ومحدد مقاسات.
- **حاسبة مقاسات ذكية** (تقترح المقاس من محيط الصدر/الطول/الوزن أو طول القدم).
- سلة مشتريات محفوظة محلياً (zustand + persist).
- إتمام الطلب مع **تحديد موقع GPS** وخيارات الدفع المحلي.
- ربط مباشر بدالة `create_order_atomic` في Supabase لحجز المخزون ذرياً.
- صفحة تتبع الطلب بشريط حالات تفاعلي وتفاصيل الدفع والمندوب.

## التشغيل
```bash
npm install
npm run dev
```
ثم افتح `http://localhost:3000`.

## الاتصال بـ Supabase
بدون ضبط المتغيرات يعمل المتجر بالبيانات التجريبية. لربط القاعدة الحقيقية:
```bash
cp .env.example .env.local
# ضِف:
# NEXT_PUBLIC_SUPABASE_URL=...
# NEXT_PUBLIC_SUPABASE_ANON_KEY=...
```

## البنية
```
app/             صفحات App Router
components/      مكوّنات الواجهة
lib/             طبقة البيانات والأنواع والحالة (store, cart-store, supabase, mock-data)
```

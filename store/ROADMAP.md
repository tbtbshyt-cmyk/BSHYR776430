# خارطة الطريق التنفيذية — محلات أبو بشار للملابس والأحذية

خطة مراحل مرتبة حسب الأولوية والأثر التجاري، مع الإشارة لما هو **موجود ✅** وما هو **ناقص ⬜**. كل مرحلة منتهية وقابلة للنشر والاختبار قبل الانتقال لما بعدها.

## ✅ المرحلة 0 — الأساس المكتمل (جاهز)

- متجر عربي RTL + Next.js 15 + TypeScript + Tailwind (ثيم فاخر).
- المنتجات/الأصناف/السلة/الطلبات/التتبع.
- لوحة الإدارة + تطبيق التوصيل + مصادقة OTP.
- البانرات، الحملات، الخصومات التلقائية، تقرير المبيعات.
- رفع صور بالجملة مع ضغط WebP + رفع صور منتج فردي.
- إدارة الذكاء الاصطناعي (محادثة + استخراج منتج من صورة + إنشاء حملة).
- إتمام الطلب عبر واتساب + رفع إثبات الدفع.
- CI/CD على GitHub، نشر Vercel/Netlify، RLS مصلّب.

> هذه المرحلة **لا يُعاد بناؤها** — نبني عليها فقط.

## 🔴 المرحلة 1 — جاهزية الإطلاق (أولوية قصوى)

الهدف: المتجر يعمل تجارياً بشكل موثوق دون ميزات تجريبية ناقصة.

- [ ] **1.1** تثبيت الهوية النصية نهائياً: "محلات أبو بشار للملابس والأحذية" في كل الواجهات والـ metadata ورسائل المتصفح.
- [ ] **1.2** التصنيف اليمني الكامل (رجالي/نسائي/أولادي/أحذية/شرابات) كأصناف فرعية، مع إعادة تصنيف المنتجات الحالية.
- [ ] **1.3** حقول منتج موسعة: SKU، التكلفة (هامش الربح)، الألوان، الفيديو.
- [ ] **1.4** محرك بحث وفلترة: نطاق سعر، مقاس، لون، توفر، ترتيب (الأحدث/الأرخص/الأكثر مبيعاً).
- [ ] **1.5** صفحات المنتج: Cross-sell (منتجات مكملة/مقترحة).
- [ ] **1.6** إصلاح/تأكيد منطق تعديل المنتج والكتالوج بعد الفحص النهائي.
- [ ] **1.7** صفحة "تم استلام الطلب" محسّنة مع زر واتساب وتتبع.
- [ ] **1.8** إضافة عملة YER فقط في البداية (تأجيل SAR/USD لمرحلة لاحقة).

**معايير القبول:** يمكن لعميل التصفح والبحث والإضافة والطلب عبر واتساب أو الدفع عند الاستلام من الهاتف دون أي خطأ.

- [ ] **2.1** Flash Sale Engine: عدّاد تنازلي + شريط "تم البيع %" + رسائل FOMO + كمية متبقية.
- [ ] **2.2** السلة الذكية: شريط تقدم للتوصيل المجاني + Upsell.
- [ ] **2.3** عروض اليوم والأسبوع (تبديل تلقائي + Countdown).
- [ ] **2.4** Dynamic Product Bundles (طقم بسعر موفّر) + زر "أضف الطقم".
- [ ] **2.5** Family Tier Discount (خصم عائلي تراكمي).
- [ ] **2.6** Smart Pricing Anchoring (سعر مشطوب + نسبة خصم) مع منع البيع تحت هامش آمن من الخادم.
- [ ] **2.7** Social Proof (إشعار شراء حي قابل للإيقاف من الإدارة).

**معايير القبول:** تظهر الخصومات تلقائياً، وتُحسب الأسعار في قاعدة البيانات، ولا يمكن تجاوز الهامش الآمن.
